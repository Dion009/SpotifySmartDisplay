# 🎵 Spotify Smart Display

An ESP32-powered Spotify Smart Display built using a 2.8" ILI9341 TFT display.

## 🚀 Features

- 🎵 Displays the currently playing Spotify song
- 🖼 Album artwork
- ⏯ Play/Pause controls
- ⏮ Previous / ⏭ Next
- 📊 Playback progress bar
- 🔊 Volume indicator
- 🕒 Live clock
- 🌦 Weather information
- 📱 Phone notifications (planned)
- 💡 RGB ambient lighting (planned)
- 🔌 Smart plug control (planned)

## 🛠 Hardware

- ESP32 Dev Module
- 2.8" ILI9341 SPI TFT Display
- XPT2046 Touch Controller
- Jumper wires
- USB Cable
